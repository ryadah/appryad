طريقة بناء APK عبر GitHub فقط
==============================

هذا المشروع لا يحتاج Android Studio على جهازك إذا كنت ستستخدم GitHub Actions.

1) ارفع مجلد المشروع بالكامل إلى مستودع GitHub جديد.
   - يفضل أن يكون اسم الفرع: main

2) من صفحة المستودع افتح:
   Actions

3) اختر:
   Build Android APK

4) اضغط:
   Run workflow
   ثم اختر الفرع main واضغط Run workflow.

5) انتظر حتى تصبح العملية بعلامة نجاح خضراء.

6) افتح عملية البناء الناجحة، ثم في أسفل الصفحة ستجد:
   Artifacts

7) نزّل:
   الدليل-الطبي-debug-apk

8) فك الضغط وستجد:
   app-debug.apk

ملاحظات مهمة
-------------
- GitHub Actions ينشئ Gradle Wrapper تلقائيا داخل بيئة البناء ثم يبني APK.
- لذلك لا يلزم وجود Android Studio أو Gradle أو gradlew على هاتفك أو جهازك.
- ملف APK الناتج Debug ومناسب للاختبار والتثبيت اليدوي.
- إذا عدلت ملفات المشروع ثم رفعتها إلى main، سيبدأ البناء تلقائيا بسبب إعداد push.
- يمكن أيضا تشغيل البناء يدويا من Actions > Build Android APK > Run workflow.

في حال فشل البناء:
------------------
افتح عملية البناء الفاشلة ثم افتح خطوة Build Debug APK أو Generate Gradle Wrapper،
وانسخ رسالة الخطأ لإرسالها للمراجعة.
